# AdGuard Home Desktop Icons

Official SVG and PNG logos are available in the [AdGuard Media Materials](https://adguard.com), which can be converted into native shortcut icons for Windows and macOS.

### Summary & Included Assets
* **`adguard_win.ico`**: Multi-resolution Windows icon (`16x16` to `256x256`).
* **`adguard_mac.icns`**: Full 10-slice macOS Retina-ready icon bundle (`16x16` up to `1024x1024` `@2x`).
* **`adguard_win_plain.svg` & `adguard_mac_plain.svg`**: Clean Inkscape source vectors.

### Instructions: Windows (10, 11)
1. Download `adguard_win.ico` (or extract it from `adguard_win.zip`) to a permanent folder.
2. Create a shortcut to your AdGuard Home dashboard URL (e.g., `http://127.0.0`).
3. Right-click the shortcut, select **Properties**, click **Change Icon...**, choose `adguard_win.ico`, and click **OK**.

### Instructions: macOS
1. Download `adguard_mac.icns` (or extract it from `adguard_mac.zip`).
2. Create a desktop URL shortcut by dragging your AdGuard Home dashboard URL from your browser address bar onto your Desktop.
3. Select the new Desktop shortcut, press **Command + I (`⌘ I`)**, and drag and drop `adguard_mac.icns` onto the small generic icon thumbnail in the top-left corner.
